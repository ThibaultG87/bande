# Câblage pas à pas (NovaBAT)

Page ouverte par le QR code de l'étiquette d'une boîte, imprimée par le module Bandes de NovaBAT.

- Toute la boîte est écrite dans l'adresse, après `#b=`. La page la relit et affiche le câblage pas à pas.
- Rien n'est envoyé ni stocké sur internet : **aucun chantier, aucun client dans ce dépôt**.
- Les fichiers `bande-code.js`, `clean.js`, `okteo/schema.js` et `okteo/connecteur.js` sont des copies de ceux de NovaBAT
  (`Sources/Bandes/web`). Quand ils changent dans NovaBAT, il faut les recopier ici.
- Dessin de la boîte et connecteurs repris d'Oktéo, avec l'accord de Kévin.

Adresse : https://thibaultg87.github.io/bande/
